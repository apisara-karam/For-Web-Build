Open [presentation.html](presentation.html) in a modern browser to view the self-contained 12-slide deck. No build, server, external assets, accounts, or dependencies are required. ## Source and assumptions

- The aggregate **1.7/5**, five-level scale, 13 area names, and seven high-importance/high-priority areas come from the assessment description in the task. The program ambition of **4.0–4.5 within 2–4 years**, suggested roadmap and module duration ranges derive from [the existing improvement plan](DATA_GOVERNANCE_IMPROVEMENT_PLAN.md).
- The referenced `image1` assessment graphic was **not included in the repository or available as a file** for this task, so it could not be embedded. The area-level *current* and *target* score cells have intentionally been labeled unverified/to confirm. Numbers mentioned beside some areas in the earlier chat cannot be safely attributed to current versus target maturity. Obtain the original scorecard, verify each row and replace the placeholders before circulating the deck as a definitive assessment.
- Yearly maturity checkpoints and per-area assessment/implementation ranges are **indicative planning assumptions**, not promises. Modules may overlap; implementation represents initial rollout, with ongoing governance thereafter. Dependencies and scope, capacity, procurement, legal requirements, and success criteria must be validated in discovery.
- The pricing slide uses **hypothetical arithmetic in USD**, not vendor prices or a quotation: 50 incremental users × assumed $30/user/month + $2,000/month cloud consumption + $90,000 one-time implementation + $4,000/month operating support = $180,000 in Year 1 and $90,000 recurring per year at the same footprint. Licensing, cloud consumption, implementation, and operating costs are separate buckets. No particular Microsoft product or license tier is mandatory. Microsoft pricing and entitlements change; validate the customer's region, agreement, user count, workloads, consumption, taxes, existing entitlements, and contract terms with Microsoft or an authorized partner.
- Microsoft Purview Data Governance and Microsoft Purview Information Protection represent different capabilities and licensing considerations. Legacy Azure Data Catalog and SQL Server Master Data Services mentioned in the earlier plan are not recommended as default new purchases. Product fit and lifecycle should be confirmed during solution selection.
